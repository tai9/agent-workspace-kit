# agent-workspace-kit v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the VieSpeak agent workflow (release layer, doctor, hooks, contract check, skills) into this repo as an npm package plus Claude Code plugin that runs in two workspace shapes, multi-repo and monorepo, from one `workspace.yml`.

**Architecture:** Bash libraries under `lib/` hold every function; thin `bin/` scripts drive them; a node CLI (`bin/agent-workspace-kit.mjs`) dispatches to those scripts and owns `init`. The one non-bash piece of core is `bin/config.mjs`, which flattens `workspace.yml` to `key=value` lines that `lib/config.sh` reads once per process. Everything ecosystem-specific enters through six seams (repo table, version adapter, store paths, contract paths, preflight endpoints, post-release commands), all read from config. Source of every function is `viespeak-project/scripts/`; strings and behaviour stay identical unless a seam forces a change, because the parity gate compares outputs byte for byte.

**Tech Stack:** bash 3.2+ (macOS default) with `set -euo pipefail`; POSIX sh for hooks; node ≥ 20 with the `yaml` package; pnpm; shellcheck; git.

**Spec:** `docs/design.md`

## Global Constraints

- Package manager is **pnpm**; the CLI is invoked as `npx agent-workspace-kit <cmd>` or, inside a consumer, `pnpm exec agent-workspace-kit <cmd>`.
- The kit is installed as a devDependency at the consumer's workspace root, so its stable path is `<workspace>/node_modules/agent-workspace-kit`. Every hook and stub locates the kit that way; nothing hardcodes a machine path.
- `lib/` has no ecosystem knowledge: no `viespeak`, no `pubspec`, no `shorebird` outside `adapters/`. Grep enforces it (Task 17 step in `bin/check`).
- The release core never branches on `shape`; only `lib/repos.sh`, the doctor and `init` do.
- Adapter contract is exactly three functions: `anchor_version`, `anchor_release`, `anchor_patch`.
- Every mutating command takes `--dry-run` and prints its plan before any change.
- Commit messages in English. Every task ends in a commit on a branch in a worktree (`.claude/worktrees/<task>`), never on `main`.
- Source of truth for extraction: `/Users/tai/Documents/personal/projects/viespeak-project/scripts/` (referred to below as `$VS`). Line numbers refer to the files as of workspace commit `bb34e4d`.
- Test harness is plain bash (`is`, `t_ok`, `t_bad`), no framework. Every test runs in a temp dir and touches no network.
- Parity gate (Task 17): `add`, `status`, `cut --dry-run` and the doctor minus its Hooks section must match VieSpeak's scripts byte for byte after ANSI stripping. `preflight` is compared per check verdict, because analyse and doctor steps moved into config-driven extras. The spec's "byte-identical" line is amended to say this in Task 17.

## Config reference (used by every task)

`workspace.yml` keys the code reads. `init` writes them; tests write them by hand.

```yaml
name: VieSpeak                  # used in generated headings
shape: multi-repo               # multi-repo | monorepo
trunk: main                     # monorepo only: the one trunk
repos:
  app:
    path: viespeak-app
    trunk: develop              # multi-repo only
    role: release-anchor        # release-anchor | service | other
    mirror: main
    guards: true                # default true; false = no relay stub, doctor skips it
  backend:
    path: viespeak-be
    trunk: main
    role: service
release:
  adapter: flutter-shorebird    # flutter-shorebird | generic-semver
  anchor_file: viespeak-app/pubspec.yaml
  tag: "released/{version}"
  release_cmd: scripts/shorebird-release.sh   # flutter-shorebird: relative to the anchor path
  patch_cmd: scripts/shorebird-patch.sh
  store_paths: [android/, ios/, pubspec, .gradle, Podfile, Info.plist, AndroidManifest, assets/]
  contract_paths: [lib/core/services/api_service, lib/core/services/app_version_service]
preflight:
  base_url_from: "env:API_BASE_URL@viespeak-app/.env.{env}"
  endpoints:
    - path: /health
      expect: '"status"[[:space:]]*:[[:space:]]*"ok"'   # regex on the body; omit = any 2xx
    - path: /api/app/version-status?platform={platform}&build=1
  extra:
    - name: flutter analyze
      run: "cd viespeak-app && flutter analyze"
contracts:                      # for contract-check; optional
  - name: promo
    paths: { app: lib/features/promo, backend: promo }
post_release:
  - "node scripts/lib/app-versions.mjs set --env-file viespeak-be/.env --platform {platform} --latest {build} {extra}"
```

`preflight.endpoints` entries may also be plain strings (`- /health`), read as `path` with no `expect`. `store_paths` entries are joined with `|` into the regex VieSpeak uses today; `assets/` becomes `(^|/)assets/`, and `.` is escaped.

#!/usr/bin/env bash
# Shared harness for test/*.test.sh. Source it first, then write tests.
set -uo pipefail
KIT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
TMP="$(mktemp -d)"
trap 'rm -rf "$TMP"' EXIT
pass=0; fail=0
t_ok()  { printf '  \033[32mok\033[0m   %s\n' "$1"; pass=$((pass+1)); }
t_bad() { printf '  \033[31mFAIL\033[0m %s\n           expected: %s\n                got: %s\n' "$1" "$2" "$3"; fail=$((fail+1)); }
is()    { [ "$2" = "$3" ] && t_ok "$1" || t_bad "$1" "$2" "$3"; }
finish() { printf '%d passed, %d failed\n' "$pass" "$fail"; [ "$fail" -eq 0 ]; }

# A git repo with one commit, identity set. Prints nothing; use the path you passed.
git_init() { # <dir>
  mkdir -p "$1"; git -C "$1" init -q -b main
  git -C "$1" config user.email t@example.com; git -C "$1" config user.name Test
  git -C "$1" commit -q --allow-empty -m "root"
}
# Append to a file and commit it. Prints the commit sha.
commit_file() { # <repo> <path> <message>
  mkdir -p "$1/$(dirname "$2")"; echo x >> "$1/$2"
  git -C "$1" add -A; git -C "$1" commit -qm "$3"; git -C "$1" rev-parse HEAD
}
strip_ansi() { sed 's/\x1b\[[0-9;]*m//g'; }

#!/usr/bin/env node
// Flatten workspace.yml to key=value lines so bash reads it once with no YAML parser.
import fs from 'node:fs';
import YAML from 'yaml';
const file = process.argv[2];
if (!file) { console.error('usage: config.mjs <workspace.yml>'); process.exit(2); }
let doc;
try { doc = YAML.parse(fs.readFileSync(file, 'utf8')) ?? {}; }
catch (e) { console.error(`workspace.yml: ${e.message}`); process.exit(1); }
const out = [];
function walk(v, p) {
  if (Array.isArray(v)) { out.push(`${p}.#=${v.length}`); v.forEach((x, i) => walk(x, `${p}.${i}`)); }
  else if (v && typeof v === 'object') { for (const [k, x] of Object.entries(v)) walk(x, p ? `${p}.${k}` : k); }
  else out.push(`${p}=${v ?? ''}`);
}
walk(doc, '');
process.stdout.write(out.join('\n') + (out.length ? '\n' : ''));
```

#!/usr/bin/env bash
# Locates the workspace and exposes workspace.yml as cfg/cfg_list/cfg_keys.
# Sourced by lib/release-common.sh after lib/out.sh. One node call per process.
KIT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

# Walk up from $WORKSPACE_ROOT (if set) or $PWD to the first workspace.yml. A
# worktree of the workspace repo (…/.claude/worktrees/<x>) resolves to the real
# checkout, where the product repos actually are.
find_workspace_root() {
  local d="${WORKSPACE_ROOT:-$PWD}"
  case "$d" in *"/.claude/worktrees/"*) d="${d%%/.claude/worktrees/*}";; esac
  while [ "$d" != "/" ]; do
    [ -f "$d/workspace.yml" ] && { printf '%s' "$d"; return 0; }
    d="$(dirname "$d")"
  done
  return 1
}
WORKSPACE_ROOT="$(find_workspace_root)" || die "no workspace.yml found above ${WORKSPACE_ROOT:-$PWD} (run 'agent-workspace-kit init' at the workspace root, or set WORKSPACE_ROOT)"
WORKSPACE_YML="$WORKSPACE_ROOT/workspace.yml"
CFG_FLAT="$(node "$KIT_ROOT/bin/config.mjs" "$WORKSPACE_YML")" || die "could not read $WORKSPACE_YML"

_cfg_escape() { printf '%s' "$1" | sed 's/[.[\*^$#]/\\&/g'; }
cfg()      { printf '%s\n' "$CFG_FLAT" | sed -n "s/^$(_cfg_escape "$1")=//p" | head -n1; }
cfg_default() { local v; v="$(cfg "$1")"; [ -n "$v" ] && printf '%s' "$v" || printf '%s' "$2"; }
cfg_list() {
  local n i=0; n="$(cfg "$1.#")"; [ -n "$n" ] || return 0
  while [ "$i" -lt "$n" ]; do cfg "$1.$i"; i=$((i+1)); done
}
cfg_keys() { printf '%s\n' "$CFG_FLAT" | grep "^$(_cfg_escape "$1")\." | sed "s/^$(_cfg_escape "$1")\.//; s/[.=].*//" | awk '!s[$0]++'; }
```

#!/usr/bin/env bash
# The repo table: the one place that knows whether the workspace is several git
# repos or one. Everything else asks these functions and never looks at shape.
shape()      { cfg_default shape multi-repo; }
repo_names() { cfg_keys repos; }
repo_path()  { printf '%s/%s' "$WORKSPACE_ROOT" "$(cfg "repos.$1.path")"; }
repo_label() { basename "$(cfg "repos.$1.path")"; }
repo_role()  { cfg "repos.$1.role"; }
repo_guards(){ cfg_default "repos.$1.guards" true; }
repo_trunk() {
  local t; t="$(cfg "repos.$1.trunk")"
  [ -n "$t" ] || t="$(cfg_default trunk main)"
  printf '%s' "$t"
}
repo_git_dir() { if [ "$(shape)" = monorepo ]; then printf '%s' "$WORKSPACE_ROOT"; else repo_path "$1"; fi; }
repo_subdir()  { if [ "$(shape)" = monorepo ]; then cfg "repos.$1.path"; fi; }
repo_git()     { local n="$1"; shift; git -C "$(repo_git_dir "$n")" "$@"; }

# Files a commit touched, relative to the repo's own path. In a monorepo the
# commit may touch other roles' directories; those are not this repo's change.
repo_changed_files() {
  local n="$1" c="$2" sub; sub="$(repo_subdir "$n")"
  if [ -n "$sub" ]; then
    repo_git "$n" show --name-only --format= "$c" -- "$sub" 2>/dev/null | sed "s#^$sub/##"
  else
    repo_git "$n" show --name-only --format= "$c" 2>/dev/null || true
  fi
}

anchor_name() {
  local n; for n in $(repo_names); do
    [ "$(repo_role "$n")" = release-anchor ] && { printf '%s' "$n"; return 0; }

import { spawnSync } from 'node:child_process';
import { fileURLToPath } from 'node:url';

const here = path.dirname(fileURLToPath(import.meta.url));

  doctor: ['bash', path.join(here, 'doctor')],
  check: ['bash', path.join(here, 'check')],
  live: ['bash', path.join(here, 'release-live')],
  'contract-check': ['bash', path.join(here, 'contract-check')],
  'install-git-hooks': ['bash', path.join(here, 'install-git-hooks')],
};
let target, args = rest;
if (cmd === 'release') {
  const sub = rest[0]; args = rest.slice(1);
  if (['add', 'status', 'preflight', 'cut'].includes(sub)) target = ['bash', path.join(here, `release-${sub}`)];
} else target = table[cmd];
if (!target) {
  console.log(`usage: agent-workspace-kit <command>
  init [--yes] [--dry-run]        set a workspace up
  doctor                          report drift
  check                           shellcheck + tests + doctor
  release add|status|preflight|cut
  live <version> [...]
  contract-check [<repo>] [<base>]
  install-git-hooks [--dry-run]`);
  process.exit(cmd ? 2 : 0);
}
const r = spawnSync(target[0], [...target.slice(1), ...args], { stdio: 'inherit' });
process.exit(r.status ?? 1);
