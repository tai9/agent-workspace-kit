# Metrics catalog

Canonical definitions so the same question asked twice returns the same
number. Until adopted, product-analyst answers define their metric
inline and add it here.

Per metric, a row: **definition · source of truth · how it lies**.
Committed definitions (a dashboard tile, an RPC, an admin page) outrank
hand-derived ones.

Sections to fill during adoption:

- **Engagement** — DAU/WAU/MAU as defined here, sessions, the unit of
  value delivered.
- **Activation** — the funnel and the true activation event (name the
  proxies as proxies).
- **Retention** — cohort definitions, day-bucketing choices.
- **Money** — revenue source of truth (almost never client events),
  paid-vs-trial-vs-promo separation, refund/sandbox contamination.
- **Product-specific surfaces** — the two or three feature areas whose
  metrics get asked about weekly.
- **Segmentation axes** — the standard cuts and where each field's truth
  lives.
